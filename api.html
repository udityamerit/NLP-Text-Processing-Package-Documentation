API Reference

Complete reference for all functions in the nlp_text_preprocessing library. Functions are grouped logically by capability — each is fully null-safe and ready for use with Pandas .apply().

Null Safety Guarantee

All functions accept None or np.nan values gracefully, returning empty strings or zeros instead of throwing exceptions. This makes it completely safe to use .apply() on messy pandas datasets.

Interactive Code Examples

Click on any function name in the reference tables below to open an interactive code popup with a copyable Python usage example and live output demonstration.

1. General Feature Extraction

Extract statistical features, readability scores, and basic counts from your raw text.

Function Parameters Return Type Description
x: str int Returns total whitespace-separated word count.
x: str int Returns total characters excluding spaces.
x: str float Returns average word length (0.0 for empty inputs).
x: str int Returns count of stop words (case-insensitive).
x: str int Returns total number of sentences.

2. Text Cleaning and Normalization

Powerful utilities for sanitizing web scraping artifacts, social media tokens, and special characters.

Function Parameters Return Type Description
x: str str Converts input text to lowercase.
x: str str Expands contractions using a contractions dictionary.
x: str str Removes all email addresses from text.
x: str str Removes HTTP/HTTPS links and www URLs.
x: str str Strips HTML/XML tags using BeautifulSoup.
x: str str Normalizes accented characters (NFKD → ASCII).
text: str str Runs the default end-to-end cleaning pipeline.

3. Linguistic Processing

NLP-centric transformations powered by spaCy and NLTK for core linguistic analysis.

spaCy Model Required

These functions require the en_core_web_sm model. Run python -m spacy download en_core_web_sm before first use.

Function Parameters Return Type Description
x: str str Lemmatizes nouns and verbs via spaCy while keeping other POS tags.
x: str list Extracts Named Entities (Persons, Orgs, Locations) as a list of tuples.
x: str list Returns a list of tuples with Part-Of-Speech tagging for each token.
