The nlp-prep command (or python -m nlp_text_preprocessing) cleans text files, CSV columns and standard input without writing Python.

nlp-prep clean INPUT [options]Cleans a .txt file (one document per line), a CSV column or standard input (-).
input
File path, or - for standard input.
-o, --output
Output file. Default: standard output.
-c, --column
CSV column that holds the text (required for .csv input).
--output-column
CSV column to write to. Default <column>_clean; use the same name to overwrite.
-m, --mode
light (default) keeps case and punctuation for transformer models; standard lowercases, drops punctuation and lemmatizes.
--lowercase
Light mode: lowercase the text.
--url-token TEXT
Light mode: replace URLs with TEXT.
--email-token TEXT
Light mode: replace emails with TEXT.
--stopwords
Standard mode: also remove stop words.
--steps a,b,c
Comma-separated step names. Overrides --mode.
--pipeline FILE
JSON file written by Pipeline.save. Overrides --mode.
Returns
cleaned text
