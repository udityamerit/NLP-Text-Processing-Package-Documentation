User guide

Task-focused recipes. Every example runs as written, and the output shown is real.

Build a pipeline

A step is the name of a built-in function, a name you registered, a callable, or a (name, kwargs) pair. Every step except the last must return a string. Names are checked when the pipeline is created, so a typo fails immediately.

Python
import nlp_text_preprocessing as tp

pipe = tp.Pipeline([
    "remove_html_tag",
    "remove_urls",
    "to_lower_case",
    "contraction_to_expansion",
    "remove_special_chars",
    "remove_extra_whitespace",
])
print(pipe.run("<p>It's GREAT!! Read https://example.com</p>"))
Outputit is great read

Pass arguments to a step

Python
import nlp_text_preprocessing as tp

pipe = tp.Pipeline([
    "to_lower_case",
    ("remove_stop_words", {"keep_negations": False}),
])
print(pipe.run("This is NOT a drill"))
print(pipe)
Outputdrill Pipeline(['to_lower_case', "remove_stop_words{'keep_negations': False}"])

End with a measurement

The final step may return a number, label, list or dictionary instead of text.

Python
import nlp_text_preprocessing as tp

pipe = tp.Pipeline(["remove_urls", "remove_html_tag", "sentiment_analysis"])
print(pipe.run("<p>I really love this! https://example.com</p>"))
Outputpos

Build step by step

Python
import nlp_text_preprocessing as tp

pipe = tp.Pipeline()
pipe.add_step("to_lower_case").add_step("remove_extra_whitespace")
print(len(pipe), pipe.run("  Mixed   CASE  "))
Output2 mixed case

Errors are explicit

Python
import nlp_text_preprocessing as tp

try:
    tp.Pipeline(["to_lowercase"])
except Exception as exc:
    print(type(exc).__name__ + ":", exc)

try:
    tp.Pipeline(["text_stats", "to_lower_case"]).run("hello")
except TypeError as exc:
    print("TypeError:", exc)
OutputValueError: Pipeline step 'to_lowercase' is not available. TypeError: Pipeline step 'text_stats' returned dict, but only the last step may return a non-string.

Work with pandas

Install the extra with pip install "nlp-text-preprocessing[pandas]". run_series keeps the index and name; missing values become empty strings.

Python
import pandas as pd
import nlp_text_preprocessing as tp

df = pd.DataFrame({"review": ["<b>LOVED</b> it!! \U0001f60d", "Not good, https://spam.io", None]})
df["clean"] = tp.Pipeline.default().run_series(df["review"])
print(df)
Output review clean 0 <b>LOVED</b> it!! 😍 loved it 1 Not good, https://spam.io not good 2 NaN

Feature table in one call

text_stats_batch returns one row of statistics per text.

Python
import pandas as pd
import nlp_text_preprocessing as tp

df = pd.DataFrame({"text": ["Short one.", "A longer sentence, with #tags and @mentions!"]})
features = tp.text_stats_batch(df, "text")
print(features[["word_count", "sentence_count", "hashtags_count", "mentions_count"]].astype(int))
Output word_count sentence_count hashtags_count mentions_count 0 2 1 0 0 1 7 1 1 1

Batch processing

Use run_batch for lists. Steps run across the whole list one after another, and the spaCy steps (lemmatize, convert_to_base, singularize_words, pluralize_words) use nlp.pipe, which is several times faster than calling them text by text.

Python
import nlp_text_preprocessing as tp

pipe = tp.Pipeline(["remove_html_tag", "to_lower_case", "lemmatize", "remove_stop_words"])
texts = ["The <b>dogs</b> were barking loudly", "She has been studying for exams"]
print(pipe.run_batch(texts))
Output['dog bark loudly', 'study exam']

Measure what cleaning changed

diff_report summarizes characters, words, URLs and emails removed between two lists.

Python
import nlp_text_preprocessing as tp

before = ["<p>Mail me@x.com</p>", "Plain text", "See https://example.com now"]
after = tp.Pipeline.default().run_batch(before)
print(tp.diff_report(before, after))
Output{'total_items': 3, 'chars_before': 57, 'chars_after': 21, 'char_reduction_pct': 63.16, 'words_before': 7, 'words_after': 5, 'word_reduction_pct': 28.57, 'emails_removed': 1, 'urls_removed': 1}

Custom steps

Register a function once and use it by name. The first argument is the text; extra keyword arguments come from the step's kwargs.

Python
import nlp_text_preprocessing as tp

import re

@tp.register_step("strip_ticket_ids")
def strip_ticket_ids(text, prefix="TKT"):
    return re.sub(rf"{prefix}-\d+", "", text)

pipe = tp.Pipeline([
    "to_lower_case",
    ("strip_ticket_ids", {"prefix": "tkt"}),
    "remove_extra_whitespace",
])
print(pipe.run("Re: TKT-4821 printer is  broken"))
Outputre: printer is broken

Plain callables work too, but only registered names can be saved to JSON.

Python
import nlp_text_preprocessing as tp

pipe = tp.Pipeline(["to_lower_case", lambda t: t.replace("colour", "color")])
print(pipe.run("Favourite COLOUR"))

try:
    pipe.to_config()
except ValueError as exc:
    print("ValueError:", exc)
Outputfavourite color ValueError: Step '<lambda>' is a custom callable and cannot be saved. Register it with @register_step('name') and use that name.

Save & reuse

Pipelines serialize to JSON, so the exact preprocessing used in training can ship with the model.

Python
import nlp_text_preprocessing as tp

import os, tempfile

pipe = tp.Pipeline(["remove_urls", ("remove_stop_words", {"keep_negations": True}), "to_lower_case"])
path = os.path.join(tempfile.mkdtemp(), "preprocess.json")
pipe.save(path)
print(open(path).read())

restored = tp.Pipeline.load(path)
print(restored.run("This is NOT bad https://x.io"))
Output{ "version": 1, "steps": [ "remove_urls", { "step": "remove_stop_words", "args": { "keep_negations": true } }, "to_lower_case" ] } not bad

For your own storage use to_config() and Pipeline.from_config(). The same file works from the command line with nlp-prep clean --pipeline preprocess.json.

Use with scikit-learn

TextPreprocessor wraps a pipeline as a transformer, so cleaning travels with the model and is applied identically at predict time. Requires pip install "nlp-text-preprocessing[sklearn]".

Python
from sklearn.feature_extraction.text import TfidfVectorizer
from sklearn.linear_model import LogisticRegression
from sklearn.pipeline import make_pipeline
import nlp_text_preprocessing as tp

texts = ["<b>Great</b> movie!", "Terrible film...", "Loved this great film", "Awful acting, terrible plot"]
labels = [1, 0, 1, 0]

model = make_pipeline(
    tp.TextPreprocessor(["remove_html_tag", "to_lower_case", "remove_special_chars"]),
    TfidfVectorizer(),
    LogisticRegression(),
)
model.fit(texts, labels)
print(model.predict(["A great movie", "Terrible!"]))
Output[1 0]

Because the steps are a parameter, grid search can tune the cleaning itself.

Python
from sklearn.feature_extraction.text import TfidfVectorizer
from sklearn.pipeline import make_pipeline
import nlp_text_preprocessing as tp

model = make_pipeline(tp.TextPreprocessor(["to_lower_case"]), TfidfVectorizer())
model.set_params(textpreprocessor__steps=["to_lower_case", "remove_stop_words"])
print(model.get_params()["textpreprocessor__steps"])
Output['to_lower_case', 'remove_stop_words']

Transformer models

BERT and GPT style models were trained on natural text. Use light_clean to remove noise only, and keep case, punctuation and word forms.

Python
import nlp_text_preprocessing as tp

raw = "<p>Can't BELIEVE it's &amp; working!! \u2764\ufe0f  https://example.com</p>"
print(tp.light_clean(raw))
print(tp.clean_text(raw))
OutputCan't BELIEVE it's & working!! ❤️ cannot believe it be work

Compare: clean_text is the classic route for bag-of-words models and removes the information a transformer uses.

Respect the token limit

Without a tokenizer, whitespace words are a rough stand-in. Pass any callable that returns tokens.

Python
import nlp_text_preprocessing as tp

text = "one two three four five six seven eight nine ten"
print(tp.truncate_text(text, max_tokens=4))
for chunk in tp.chunk_text(text, max_tokens=4, overlap=1):
    print(chunk)
Outputone two three four one two three four four five six seven seven eight nine ten

With a real tokenizer, counts match what the model sees. Leave room for special tokens such as [CLS] and [SEP].

Python
import nlp_text_preprocessing as tp

from transformers import AutoTokenizer

tok = AutoTokenizer.from_pretrained("bert-base-uncased")
chunks = tp.chunk_text(long_document, max_tokens=500, overlap=50, tokenizer=tok)

Mask personal data

mask_pii redacts emails, card numbers, US Social Security numbers and phone numbers. Set names=True to add person names (uses spaCy and is statistical, so review the output when privacy matters).

Python
import nlp_text_preprocessing as tp

record = "Contact Priya Sharma at priya@example.com or 555-123-4567. Card 4111 1111 1111 1111."
print(tp.mask_pii(record))
print(tp.mask_pii(record, token="<PII>", names=True))
OutputContact Priya Sharma at [REDACTED] or [REDACTED]. Card [REDACTED]. Contact <PII> at <PII> or <PII>. Card <PII>.

Count first, remove selectively, or mask everything.

Python
import nlp_text_preprocessing as tp

text = "Email a@b.com, call 555-123-4567, see https://example.com"
print(tp.count_emails(text), tp.count_phone_numbers(text), tp.count_urls(text))
print(tp.remove_phone_numbers(tp.remove_emails(text)))
Output1 1 1 Email , call , see https://example.com

Moderate content

The moderation helpers are transparent keyword baselines. They are useful for triage and dashboards, not as a replacement for a trained classifier.

Python
import nlp_text_preprocessing as tp

comment = "You damn idiot. CLICK HERE!!! BUY NOW http://spam.example"

print("profane:", tp.detect_profanity(comment))
print("toxicity:", tp.detect_toxicity(comment))
print("spam:", tp.detect_spam_signals(comment)["is_spam_candidate"])
print(tp.censor_profanity("What the hell, damn it"))
Outputprofane: True toxicity: 0.5 spam: True What the ****, **** it

Understand a score

toxicity_report lists what matched and what a negation cancelled, so reviewers can see why a text scored as it did.

Python
import nlp_text_preprocessing as tp

print(tp.toxicity_report("You idiot. I do not hate you."))
Output{'score': 0.5, 'matches': [{'word': 'idiot', 'weight': 1.0, 'targeted': True}], 'ignored': [{'word': 'hate', 'weight': 1.0, 'targeted': True}]}

Tune the word list

Python
import nlp_text_preprocessing as tp

print(tp.detect_profanity("what the hell", include_mild=False))
print(tp.detect_profanity("that was a frack-up", extra_words=["frack"]))
OutputFalse True

Command line

The nlp-prep command (or python -m nlp_text_preprocessing) cleans text without writing Python. Input is a .txt file with one document per line, a CSV column, or standard input (-).

Terminal
# one document per line, light cleaning for transformer models (default)
nlp-prep clean reviews.txt -o cleaned.txt

# a CSV column; the result goes to <column>_clean
nlp-prep clean reviews.csv --column review -o cleaned.csv

# classic cleaning: lowercase, no punctuation, lemmatized, stop words removed
nlp-prep clean reviews.txt --mode standard --stopwords

# your own steps, or a saved pipeline
nlp-prep clean reviews.txt --steps remove_urls,to_lower_case
nlp-prep clean reviews.txt --pipeline preprocess.json

It also works in shell pipelines:

Terminal
echo "<b>Hello   WORLD</b> https://example.com" | nlp-prep clean - --url-token "[URL]"
OutputHello WORLD [URL]
