Why this package

Preparing text is the first step of almost every NLP or machine learning project, and it is usually written from scratch each time. nlp-text-preprocessing turns that repeated work into a small, consistent toolkit: more than 60 single-purpose functions, an extensible Pipeline, and defensive handling of messy input, so you spend your time on the model and not on the cleaning code.

How it helps

  • Faster to start. Clean, analyse and visualise text with one install and one import.
  • Consistent results. The same named steps give the same output in every project and for every teammate.
  • Safe on real data. Missing values and odd types do not stop a long run.
  • Ready for both worlds. Use the full cleaning path for classic models, or the light path for transformers.

How it differs from the traditional way

AspectTraditional approachWith nlp-text-preprocessing
Cleaning stepsRegular expressions copied between notebooks, each slightly different.Named, tested functions such as remove_urls and remove_html_tag.
Missing valuesNone or NaN in a column raises an error half way through a run.Every function treats None, NaN, pd.NA and bytes as empty text.
LibrariesWire up re, BeautifulSoup, NLTK, spaCy and TextBlob separately, each with its own setup.One import and one API. Heavy libraries load only when a function needs them.
ReuseThe preprocessing lives in a script that is hard to share or reproduce.A Pipeline is a list of steps. Save it to JSON and load it back anywhere.
Speed on large dataCall the spaCy model once per document.run_batch and run_series use nlp.pipe for the spaCy steps, about 2x faster with identical output.
DownloadsModels and corpora are fetched silently, or fail on first use.Nothing downloads on its own. check_resources() reports what is missing and download_nltk_packages() fetches it once.
Transformer modelsAggressive classic cleaning can strip punctuation and casing that transformer models use.light_clean, truncate_text and chunk_text prepare text for transformer tokenizers.

A typical hand-written cleaner and the same job as a pipeline:

Python
import re

text = "<b>Fresh   TEXT!</b> Visit https://example.com"
text = re.sub(r"<[^>]+>", " ", text)
text = re.sub(r"https?://\S+", "", text)
text = re.sub(r"[^\w\s]", "", text)
text = re.sub(r"\s+", " ", text).strip().lower()
print(text)
Outputfresh text visit
Python
import nlp_text_preprocessing as tp

text = "<b>Fresh   TEXT!</b> Visit https://example.com"
pipe = tp.Pipeline(["remove_html_tag", "remove_urls", "remove_special_chars", "remove_extra_whitespace", "to_lower_case"])
print(pipe.run(text))
print(repr(pipe.run(None)))
Outputfresh text visit ''
The sentiment, profanity, toxicity and spam helpers are transparent keyword baselines. They are useful for quick checks and exploration. Use a trained model for anything high-stakes.

Quick start

Install the package, then run a built-in pipeline on a messy string.

Terminal
python -m pip install nlp-text-preprocessing
Python
import nlp_text_preprocessing as tp

text = "<b>Fresh   TEXT!</b>"
print(tp.Pipeline.default().run(text))
Outputfresh text

Use functions directly, or chain them. The last step of a pipeline may return anything, such as a count or a sentiment label.

Python
import nlp_text_preprocessing as tp

review = "<p>Loved it!! Visit https://example.com for more.</p>"

pipe = tp.Pipeline(["remove_html_tag", "remove_urls", "to_lower_case", "remove_special_chars", "sentiment_analysis"])
print(pipe.run(review))
print(tp.text_stats("Hello world. NLP is fun!")["word_count"])
Outputpos 5
The first call that needs a spaCy model, NLTK corpus or TextBlob data tells you what is missing. Run tp.check_resources() to see the status, or follow Models & resources.

What is inside

Every function takes plain text, treats None, NaN and bytes as empty text, and imports heavy libraries only when it needs them.
