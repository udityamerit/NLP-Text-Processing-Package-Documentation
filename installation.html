Installation

Set up an isolated environment and install version 0.5.1 from PyPI. Python 3.9 or later is required.

Create an environment

Use a virtual environment. Python 3.9 or later is required.

Windows

PowerShell
py -3.11 -m venv .venv
.\.venv\Scripts\Activate.ps1

macOS

Terminal
python3 -m venv .venv
source .venv/bin/activate

Linux

Terminal
python3 -m venv .venv
source .venv/bin/activate

Conda

Terminal
conda create -n nlp-docs python=3.11
conda activate nlp-docs

Install the package

Terminal
python -m pip install nlp-text-preprocessing

Add extras only for the features you use. Put the extra name in brackets, and quote it so zsh does not expand it.

Terminal
python -m pip install "nlp-text-preprocessing[pandas,sklearn]"

Check the installed version:

Python
from importlib.metadata import version
import nlp_text_preprocessing as tp

print(version("nlp-text-preprocessing"))
print(tp.__version__)
Output0.5.1 0.5.1
Importing the package downloads nothing, and import nlp_text_preprocessing stays fast because spaCy, TextBlob and NLTK load on first use.

Models & resources

Counting words and normalizing whitespace need no extra data. Language functions use a spaCy model and NLTK corpora. Install them once while you are online:

Python
import nlp_text_preprocessing as tp

tp.download_nltk_packages()

This fetches the NLTK data (punkt_tab, wordnet, omw-1.4) and the spaCy model en_core_web_sm. Add include_sentiment_corpus=True for the legacy Naive Bayes sentiment method. To install the spaCy model yourself:

Terminal
python -m spacy download en_core_web_sm

Check what is installed

Python
import nlp_text_preprocessing as tp

print(tp.check_resources())
Output{'spacy_model': True, 'nltk': {'punkt_tab': True, 'wordnet': True, 'omw-1.4': True}}

The same check is available from the terminal, and --download installs whatever is missing.

Terminal
nlp-prep resources
nlp-prep resources --download

Automatic download

By default nothing is downloaded behind your back. Set this variable to let get_spacy_nlp() fetch a missing model on first use, which is handy in notebooks and CI.

Terminal
# macOS / Linux
export NLP_TEXT_PREPROCESSING_AUTO_DOWNLOAD=1

# PowerShell
$env:NLP_TEXT_PREPROCESSING_AUTO_DOWNLOAD = "1"
